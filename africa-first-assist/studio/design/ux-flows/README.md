# UX flows (user's point of view)

Source of the UX flows on the FigJam board: https://www.figma.com/board/MaaGiM0gtCrGJ7VgiB053Z

| File | Flow |
|---|---|
| U00-app-map.mmd | App map: what people can reach |
| U01-onboarding.mmd | Getting started and adding my cover |
| U02-sos.mmd | I need help now: SOS |
| U03-roadside.mmd | My car broke down: roadside help and status |
| U04-buy-travel-cover.mmd | I need travel cover for my visa |
| U05-travel-claim.mmd | Getting my money back: travel claim |
| U06-wallet-companion.mmd | Am I covered? Wallet and travel companion |
| U07-ai-assistant.mmd | Asking a question: AI assistant, a person always reachable |
| U08-v2-tell-us-by-voice.mmd | V2 concept: tell us what happened by voice or photo |

Rules: each box is a screen or a message the user sees; branches are the user's choices or what happens to them; technical behaviour appears only as the message the user sees. Topics owned by other AFA teams are raised as questions, not decided here (decisions.md, 2026-11-19).

`design/flows/` holds earlier system-level notes. They are out of the UX scope and are not part of the pitch.
